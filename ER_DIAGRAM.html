Project Management System

DATABASE SCHEMA DESIGN

USERS
id PK
full_name VARCHAR
email UNIQUE
password VARCHAR
created_at DATETIME
PROJECTS
id PK
name VARCHAR
description TEXT
status VARCHAR
userId FK
start_date DATETIME
TASKS
id PK
name VARCHAR
description TEXT
priority VARCHAR
status VARCHAR
projectId FK
due_date DATETIME

RELATIONSHIPS

1. USERS.id → PROJECTS.userId | 1 : N | One user can create and own multiple projects.
2. PROJECTS.id → TASKS.projectId | 1 : N | One project can contain multiple tasks.
3. Foreign keys maintain referential integrity with cascading deletes (deleting a project deletes its tasks).
PK = Primary Key FK = Foreign Key UNIQUE = Unique Value
